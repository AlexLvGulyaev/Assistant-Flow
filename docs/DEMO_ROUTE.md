# Маршрут проверки демо — Assistant Flow

Как быстро убедиться, что бот живой: открыть Telegram, сменить режим
и проверить, что ответ опирается на источники.

## Маршрут проверки

1. **Открыть** [бота в Telegram](https://t.me/PEn06_Career_Consultant_bot) →
   **отправить** /start → **увидеть** приветствие и список режимов
   (текст, RAG, OCR, генерация картинок).
2. **Задать** карьерный вопрос в текстовом режиме, например:
   - «Объясни простыми словами, что такое инфляция»
   → **получить** ответ на русском.
3. **Переключить** режим командой `/mode rag` → **задать** вопрос по
   карьерным материалам базы → **проверить**, что источник в ответе —
   файл из базы, и в админ-консоли видны найденные чанки.
4. **Отправить** фото с текстом и подпись «распознай текст» → **увидеть**
   распознанную OCR-подпись: мультимодальность в действии.

## Что ещё доступно

- `/stats` — статистика сессии; `/reset`, `/clear` — сброс контекста.
- Административная консоль: трассировка запросов, найденные чанки и
  диагностика RAG, настройка поиска и backend векторного хранилища
  (см. [README.md](https://github.com/AlexLvGulyaev/Assistant-Flow/blob/main/README.md)).
- Полные сценарии проверки:
  [DEMO_SCENARIOS.md](https://github.com/AlexLvGulyaev/Assistant-Flow/blob/main/docs/DEMO_SCENARIOS.md).
